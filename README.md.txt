# 🏗️ AI Material & Asset Standardization Engine

Transform chaotic, inconsistent material names into **international standard formats** compliant with ISO 8000, ECLASS, UNSPSC, and IEC 61360.

## Features

- ✅ **AI-Powered** - Uses LLM (GPT-4/Claude) for intelligent standardization
- ✅ **Dynamic Learning** - Learns from your existing master data
- ✅ **Zero Hardcoding** - All rules in config.yaml, fully configurable
- ✅ **Asset Detection** - Auto-detects assets vs consumables
- ✅ **HSN Auto-Assignment** - Harmonized System Nomenclature codes
- ✅ **International Standards** - ISO, ECLASS, UNSPSC, IEC compliant
- ✅ **Review Queue** - Flags low-confidence items for human review
- ✅ **Batch Processing** - Handles 10,000+ rows
- ✅ **Excel/CSV** - Upload and download in both formats
